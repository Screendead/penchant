# The manifest advertises a standalone installable app with nothing cached to fall back on

**Severity:** medium

web/manifest.json declares standalone display plus four icon sizes including maskable variants, which is what browsers use to decide the site is installable. With no service worker generated by current Flutter and none supplied here, an installed standalone window off the network fails exactly like any ordinary uncached page load.

The manifest also has no scope member, leaving the navigation boundary to the specification's implicit default rather than a stated one.

## Evidence

- `web/manifest.json:5` — `"display": "standalone",`
- `web/index.html:36` — `<script src="flutter_bootstrap.js" async></script>`
- **`WebFetch https://docs.flutter.dev/platform-integration/web/faq`** → `Flutter no longer generates or manages a service worker by default.`
